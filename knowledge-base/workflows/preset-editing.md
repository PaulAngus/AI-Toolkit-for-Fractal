# Edit preset settings and connected routing

For automatic cables and shunts between caller-chosen occupied grid points, use [automatic audio paths](../../docs/automatic-audio-paths.md). The deterministic path becomes an ordinary edit bundle, preserves existing blocks/cables and exposes sharing and feedback intent for review.

For multiple saved targets, use [general edit batches](../../docs/batch-editing.md): one reviewed order, shared transport, individual verified transactions, durable progress and query-only interruption reconciliation. The existing planner supplies each item's compound operations; no target reuses another model's fields or constants.

Use the shared [general editing planner and executor](../../docs/preset-editing.md) for a caller-selected preset on FM9, FM3 or Axe-Fx III. Begin with a complete integrity-checked saved capture and recorded model, firmware and capacity. Resolve exact instances and semantic fields from the contained model catalogue.

State the persistence intent explicitly: verified temporary edit buffer or Save/Reload. Plan scene names, per-scene channel/bypass assignments, mapped parameters, complete channel/block template copies, Scene MIDI messages and chosen connected grid changes together. New instances need complete same-model/firmware template bytes. Choose removal/disconnection/replacement policies and grid coordinates explicitly; do not invent defaults or infer the user's intended sound.

Review affected scenes, requested/effective saved values, before/after routing graph and complete original/result hashes. Preserve unrelated bytes and saved default scene. Execution compares fresh saved and loaded state with the baseline before upload and Save, then verifies complete images and renamed live scenes or changed live Scene MIDI tables. If hardware recompresses an edit, compare the independently decoded whole body plus every opaque header/trailer byte, allowing differences only in the compressed region and CRC. Retain the actual saved wire image and hash for the receipt and exact later undo preflight. The routing review includes fixed Send/Return links and I/O-conditioned paths; new feedback needs explicit intent. Stop uncertain attempts without replay; retain captures and use query-only reconciliation. A completed saved receipt permits explicit original-image undo only while its result remains current.

The implementation is common across all model definitions; physical qualification and exact-field source scope are separate. See [validation](../../docs/preset-editing-validation.json), [source-qualified read profiles](../../docs/editing-read-profiles.md) and [MCP contracts](../../docs/mcp.md). Additional built-in physical scales, named modifier curve fields, global I/O configuration and cross-model conversion require further semantic mappings.

[Capture-backed authoring](../../docs/calibrated-authoring.md) supports exact observed block, Scene Ignore and modifier values, plus modifier source edits and complete modifier templates. Modifier witnesses bind a slot, source/target assignment, one saved word and the unchanged target-block context. Calibrations are validated offline; physical labels remain caller-declared, and execution uses the existing exact review and preservation contract.

For built-in physical setters and named modifier points/endpoints, query the [scale catalogue](../../docs/builtin-scales.md) for the exact recorded model/firmware. Use `physical_value` and the declared unit; preserve modifier ownership and all unrelated words. Axe-Fx III 32.02 also exposes exact saved-normalized fractions for modifier Scale, Offset, Attack and Release; these are wire fractions, not display values or milliseconds. Exact caller-labelled display values can be used through matching modifier calibration witnesses. The Damping Type raw index can be read or copied one word from a complete same-binding/same-firmware donor, without guessing index labels.
