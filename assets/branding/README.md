# Project logo

[`logo.png`](logo.png) is the canonical project logo for AI Toolkit for Fractal, with headline edges aligned to the case width and compact framing. Use this path for documentation and other project branding. It is an unchanged copy of `ai-toolkit-for-fractal-logo-aligned.png`. Earlier framing and typography variants are retained.

The open toolkit contains an original effects-grid design, with parallel signal paths and restrained block outlines inspired by FM9-Edit. It represents this independent community project.

The PNG has a white background. The original selected concept is `../../design/logo-concepts/04-toolkit-v6-routing.png`; subsequent framing and typography edits are recorded in `prompt-tight-framing.json`, `prompt-balanced-type.json`, and `prompt-aligned-type.json` in that directory. It was created using built-in imagegen.
